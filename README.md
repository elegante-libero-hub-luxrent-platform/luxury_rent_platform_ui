# Luxury Rent Platform UI

A modern web interface for a luxury rental platform that allows users to browse, rent, and manage luxury items like designer clothing and accessories.

## Overview

This is the frontend user interface for a luxury rental platform where customers can:
- Browse a catalog of luxury items (designer clothing, bags, accessories)
- View rental pricing and availability
- Manage their rental orders
- Access their user profile
- Authenticate and login to the platform

## Features

- **Home Page**: Welcome page with platform overview
- **Catalog**: Browse available luxury items with pricing
- **My Orders**: View and manage rental orders
- **Profile**: User account management
- **Login**: User authentication

## Development

The application uses a simple client-side routing system that:
- Listens for hash changes in the URL
- Renders appropriate content based on the current route
- Provides a seamless single-page application experience
